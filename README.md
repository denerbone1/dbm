# Denerbone's Math (DBM)

> Mathn't.

## What is this?

DBM is a mathematical notation system.

Why?

Because apparently normal mathematics wasn't confusing enough.

It is written in Rust, which means it is legally required to be fast, even if nobody asked.

## Features

- Numbers. Probably.
- Addition, but with `~`.
- Subtraction, but with `|||`.
- Powers using `##`, because two hashtags are mathematically superior to one.
- Square roots using `V_`.
- A calculator GUI.
- A library for embedding DBM into other applications.
- Tests, because sometimes even DBM needs therapy.
- A completely unnecessary amount of symbols.

## Example

```text
2~2
```

Result: `4`

Revolutionary.

```text
2##3
```

Result: `8`

The computer has successfully discovered multiplication's weird cousin.

```text
V_{9}
```

Result: `3`

Rooting for you.

## Installation

1. Download the repository.
2. Install Rust.
3. Sacrifice a USB cable to the compiler.
4. Run:

```bash
cargo run --bin dbm-gui
```

Congratulations. You now have a calculator.

You could have used Windows Calculator, but where's the fun in that?

## Library

DBM can also be used as a Rust library.

You can parse expressions, evaluate them, and convert numbers.

In other words, you can make another program suffer from the same notation.
